# 真机验证指南与记录

## 1. 自动化链路验证记录（2026-10-23）

测试环境：Windows 11 + Python 3.12.10 + adb 1.0.41 + scrcpy-server v5.0.1
设备：Xiaomi 24129PN74C（Android 16，USB）／Redmi 25102RKBEC（Android 9，无线 127.0.0.1:5555）

| 项目 | 结果 | 备注 |
| --- | --- | --- |
| 会话建立 | ✅ 0.79 s | push + forward + app_process + 双通道连接 |
| 首帧延迟 | ✅ 0.15 s | 从连接成功到第一帧解码完成 |
| 视频流解析 | ✅ | codec id = `0x68323634`（"h264"）；session meta 574x1280 |
| 解码性能 | ✅ 2.1 ms/包 | 574x1280 软解，远低于帧间隔预算 |
| 动态画面帧率 | ✅ 87.8 fps | 帧间隔 p50 = 9 ms、p90 = 15 ms |
| 静态画面帧率 | ～11 fps | 正常现象：画面无变化时编码器不产帧 |
| 控制通道 | ✅ | `GET_CLIPBOARD` 可正常收发 |
| 会话关闭 | ✅ | socket/子进程/端口转发清理正常 |

验证中发现并修复的问题：

1. **scid 溢出**（严重）：`Integer.parseInt(scid, 16)` 为有符号解析，
   scid ≥ 0x80000000 时 server 启动即抛 `NumberFormatException`，
   表现为「约一半概率连接超时」。已改为生成 31 位 scid 并加回归测试。
2. **假连接**：`adb forward` 先接受本地连接、后探设备端 socket，
   server 未就绪时 connect 成功但立即 EOF。已按 scrcpy 设计读取 dummy byte 校验 + 重试。
3. **jar 清理竞争**：上一会话的 `CleanUp` 线程可能删掉新推送的 server 文件。
   已加启动重试（失败时清理残留进程）+ 失败时输出 server 日志。
4. **v5.x 流封装变更**：单 socket 名按序 accept、12B 帧头成帧，
   与 2.x「双 socket 名 + 裸流」不同，解析层已重写（详见 [scrcpy-protocol.md](scrcpy-protocol.md)）。
5. **键盘打字失败**：scrcpy 的文本注入（按键字符映射）无法注入中文，
   且手机端输入法会把数字 / 符号当候选词吞掉（实测 `HELLO123` 变成 `HELLO3`）；
   PC 端输入法又会把按键吞进组合（预编辑）不上屏。
   已改为默认「剪贴板粘贴」输入（实测中文+数字完整上屏），
   并补上预编辑显示、组合期间防重复输入、「按键模拟」游戏模式。
6. **断连后异常刷屏**：连接断开后每次鼠标移动都抛未捕获异常打一屏 traceback。
   已限频提示 + 状态栏断连提示。

## 2. 手动 GUI 验证清单

运行 `python -m mobilecast --doctor` 确认环境后，`python -m mobilecast` 启动。

### 基础投屏

- [ ] 设备列表显示设备型号与序列号
- [ ] 双击设备（或点「连接」）弹出投屏窗口，画面清晰、延迟可接受（<100ms）
- [ ] 拖动 / 缩放窗口画面不变形（letterbox 正确）
- [ ] 手机旋转屏幕，画面方向跟随
- [ ] 同时连接第二台设备，两个窗口互不干扰

### 键鼠操控

- [ ] 鼠标左键点击应用图标能打开应用
- [ ] 按住拖动能滑动列表；滚轮能滚动页面
- [ ] 鼠标右键 = 返回键；中键 = Home 键
- [ ] **剪贴板粘贴模式**（默认）：键盘输入英文+数字完整上屏（如 `abc123`）
- [ ] 中文输入法打字：组合文本显示在画面下方，选词后上屏
- [ ] 切到「按键模拟」模式：字母键直达手机游戏 / 应用
- [ ] 方向键 / Enter / Backspace / Esc 行为正确

### 画质

- [ ] 状态栏显示 `设备 1200x2670@120Hz · 串流 … · … fps`（机型分辨率/刷新率不同则对应显示）
- [ ] 默认即为设备原始分辨率
- [ ] 「画质…」切换 720p / 60fps 后自动重连，画面变清晰度下降但更流畅
- [ ] 切回原始分辨率恢复正常

### 剪贴板与文件

- [ ] PC 复制文字 → 手机任意输入框粘贴可见
- [ ] 手机复制文字 → PC 记事本粘贴可见（需手机在前台复制）
- [ ] 工具栏「粘贴到设备」按钮可用
- [ ] 关闭「剪贴板同步」后双向均不同步
- [ ] 拖一张图片进投屏窗口 → 手机相册出现该图片（媒体库扫描）

### 无线连接

- [ ] USB 连接状态点「启用无线调试」→ 提示地址
- [ ] 拔掉 USB 线 →「连接网络设备…」输入地址能重新连上
- [ ] 无线模式下画面延迟与 USB 差别可接受

### 稳定性

- [ ] 连续开关投屏窗口 5 次无报错
- [ ] 手机锁屏 / 解锁后画面恢复
- [ ] 拔掉 USB 线（或断开无线）后窗口提示断开，程序不崩溃
- [ ] 关闭主窗口后所有子窗口与后台进程退出（任务管理器无残留 adb）
